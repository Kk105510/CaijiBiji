# FF14 国服随身笔记 · CaijiBiji

三合一手机网页：制作笔记、采集笔记（采矿工 / 园艺工）、钓鱼笔记（捕鱼人）。**黑白极简**、中文、单 HTML 文件部署。

## 功能

- 左边按每 5 级分段，右边滑动物品列表；点击物品打开详细资料（手机为底部抽屉）。
- 制作配方显示材料及数量；点击「铁矿」等可采集材料，即跳转到采集笔记中该物品的采集地点，可返回上一项；鱼类材料也可跳转到钓鱼笔记。
- 采矿 / 园艺显示地图、区域、采集点 X / Y；钓鱼笔记显示钓场 X / Y、参考鱼饵，点坐标可以复制。
- 搜索、收藏、制作次数调节、复制材料清单。

## 上传到你的 GitHub 仓库

仓库：**https://github.com/Kk105510/CaijiBiji**

1. 解压这个 ZIP，会看到 `index.html` 和 `README.md`。
2. 打开仓库主页，点 **Add file → Upload files**。上传**解压后的两个文件**（不要只上传 ZIP），然后点 **Commit changes**。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，点 **Save**。
4. 页面部署成功后，通常可以访问：**https://kk105510.github.io/CaijiBiji/**（部署完成前打不开属于正常现象）。

如果仓库还完全空白、找不到 **Add file**，可以点击 **creating a new file**，填 `README.md` 并保存，再返回仓库上传 `index.html`。或者在仓库主页找 **uploading an existing file** 链接。

## 数据源与限制

- 国服中文名称 / 配方 / 采集点关联数据：<https://github.com/InfSein/ffxiv-datamining-mixed> 的 `chs/*.csv`。
- 采集坐标、钓场参考中心及鱼饵：<https://github.com/ffxiv-teamcraft/ffxiv-teamcraft> 的数据文件。
- 网页需要联网读取公开数据，初次打开会读取较大的国服物品表（约 19 MB）。网络不通或 GitHub/CDN 被限制时，笔记可能加载失败。
- 采集 X/Y 是社区记录的节点/区域参考位置，不是所有随机刷新的点位；钓场 X/Y 是钓场中心。部分节点尚无可靠坐标时页面会明确显示缺失。
- 钓鱼参考鱼饵不保证钓获；稀有鱼可能还要求天气、时段、直感、以小钓大等条件，本版暂不提供完整限制。
- 国服与国际服数据可能存在版本差异，特别是 Teamcraft 提供的坐标或鱼饵资料。如发现不一致，以游戏内实际情况为准。
- 本站为非官方工具，不索取账号或游戏角色信息，Square Enix 游戏及素材权利归相关权利人。

## 技术说明

整个页面都在 `index.html` 中，使用浏览器 `fetch()` 读取数据；不需要安装 Node.js、数据库或服务器，也不需要另外部署 JS/CSS。

已使用模拟数据对「查看配方 → 点击材料 → 跳转采集坐标」「钓鱼 → 钓场坐标 / 鱼饵」进行基本交互测试，并做 JavaScript 语法检查。**由于本地测试环境无法直接联网访问全部真实大型 CSV，尚未验证在线全量数据加载及各级配方准确性。**
